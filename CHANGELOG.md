# Changelog

This changelog records physical-development and research-documentation milestones without exposing private firmware history.

## PIKU V2.0.1

- Expanded environmental and hazard sensing
- Improved autonomous behavior
- Added servo-mounted ultrasonic inspection and radar visualization
- Added manual LEFT / FRONT / RIGHT focused inspection
- Integrated direction-aware proximity alarms
- Introduced an advanced mobile-friendly local dashboard
- Supported direct SoftAP and configured Home Wi-Fi control
- Completed documented final integrated physical testing
- Separated advanced firmware into a private source repository

## Earlier platform direction

- **PIKU V1:** foundational mobile robotics and obstacle-avoidance experiments
- **PIKU V2:** ESP32 connectivity and environmental-monitoring integration

Planned V2.1 and V3 research directions are documented separately and are not included as completed changes.
